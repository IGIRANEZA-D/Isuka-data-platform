Forecast methodology

Understanding the Forecast

A transparent guide to what the forecast measures, how it is tested, and where its limits matter.

What is being predicted?

The system estimates production and post-harvest loss for the next supported period for a district and crop. The map combines crop estimates into a production-weighted district estimate. A large crop therefore matters more to the district result than a very small crop.

Where the information comes from

The model uses real Rwanda agricultural survey production records from 2020 through 2025. The records are grouped by district, crop, year, and season. Duplicate records are removed, district names are standardized, and known invalid loss records are excluded from loss calculations.

How loss is calculated

When a valid total loss value is available, it is used once. If it is not available, the separate loss causes are added. Separate other-loss and stolen-quantity fields are then included. A row is rejected for loss modeling when its reported loss is greater than its production.

How the model is trained

An offline Gradient Boosting regression model is trained using historical district-crop observations. It uses the previous season's loss rate, previous season's weighted production, and the season indicator. A seasonal weighted historical average is also calculated, and the displayed ensemble combines the model and the baseline.

The model is trained before the page is opened. The browser only reads the saved forecast artifact. No model is trained during a page request.

What this model cannot see

Rainfall, pests, prices, and policy changes are not part of the training data. In this model, the season indicator has Not available importance for production and Not available for loss. Recent production and recent loss rate are what actually drive it. Not available forecast pairs are flagged low-confidence because their history has limited variation.

How should decisions use it?

Use the forecast as an early signal for where to investigate, prepare storage, review practices, or request better local information. Do not treat it as a guaranteed harvest result. A red map area means “needs attention,” not “this district will definitely lose 30%.”
